# 地块 WOFOST 报告结构（get_wofost_report）

WOFOST 是地块情况、地块分析、地块报告中的重点分析来源，聚焦**作物模型模拟结果、生育进程、产量/生物量、水分/养分平衡、极端天气影响和模型风险建议**。字段提取规则见 `sono-mcp/references/tool-wofost-report.md`。

所有 WOFOST 数值必须表述为“模型模拟/预测”，不能写成实际测产、实测产量或已经发生的业务结果。

本规则已内置 KPI 分组、图表选择、变量含义、异常解释和农事建议口径；生成回答时只引用 WOFOST payload 中存在或可追溯计算的事实值。

---

## 适用意图

以下地块级意图优先使用 WOFOST：

- “这个地块情况怎么样”
- “分析这个地块”
- “生成地块报告”
- “地块长势/生育进程/产量预测/水分平衡”
- “WOFOST 报告/作物模型/生长模拟”

如果缺少 `cid` 或 `plot_id`，用 Markdown 说明缺口；不要用 `get_plot_info` 冒充 WOFOST 模型报告。

---

## 报告组织（3-6 张卡片）

优先顺序：

```txt
metric(KPI摘要) -> chart(生物量/产量) -> chart(水分/氮素/物候/逆境) -> recommendation -> 链接
```

报告容量有限时，优先保留：

1. 核心 KPI 摘要。
2. 生物量/产量形成图。
3. 水分平衡或水分胁迫图。
4. 模型风险建议。

不要让 `get_plot_info` 基础快照挤掉 WOFOST 图表。

## KPI 摘要卡片

### 1. metric — 核心农学与经济指标

来源：`summary_report_json`、`terminal_report_json`、`csv_content[]` 最后有效值或已聚合字段。

推荐 items：

| label | 来源字段 | 说明 |
|---|---|---|
| 预测干重产量 | `TWSO` / `summary_report_json.TWSO` | 模型预测干重产量，单位通常为 kg/ha |
| 总地上生物量 | `TAGP` | 模型模拟地上部总生物量 |
| 最大叶面积指数 | `LAIMAX` 或日序列最大 `LAI` | 反映冠层光能捕获能力 |
| 收获指数 | `HI`，或 `TWSO / TAGP` 可计算时生成 | 禾谷类理想约 0.45-0.55；块根块茎类常见 0.60-0.80 |
| 水分胁迫天数 | `WATER_STRESS_DAYS`，或按水分胁迫规则统计 | 仅在字段或可追溯日序列存在时生成 |
| 缺氮受限天数 | `N_DEFICIENCY_DAYS`，或按 `NNI < 1.0` 统计 | 只统计建群后有效阶段 |
| 最终累积氮吸收量 | `NuptakeTotal` 最后有效值 | 单位通常为 kg N/ha |
| 成熟期植株氮浓度 | `FINAL_N_CONCENTRATION` 或可追溯计算值 | 作物类型不明时只描述相对风险 |
| 单位耗水干产量 | `TOTAL_WUE_ET` 或可追溯计算值 | 水分利用效率，单位通常 kg/m3 |

空值、`NaN`、无法追溯计算来源的指标跳过。不要为了凑满 KPI 编造值。

块根/块茎类作物（如甜菜、马铃薯）如果用户询问鲜重，可说明干重到鲜重通常需结合含水率折算；仅在明确作物类型和换算假设时给出“模型估算鲜重范围”，不要当作实测。

## 图表卡片

### 2. chart — 全株生物量积累与分配

对应资料图表：`biomass`。

来源：`csv_content[]` 或 `summary_report_json` 中的有效序列。

优先字段：

| 字段 | 含义 |
|---|---|
| `TAGP` | 地上部总生物量，产能底盘 |
| `WSO` / `TWSO` | 贮藏器官/块根/籽粒干物质，经济产量核心 |
| `WRT` / `TWRT` | 根干物质 |
| `WLV` / `TWLV` | 叶干物质 |
| `WST` / `TWST` | 茎干物质 |

推荐 ECharts：

- 多序列 `line`：展示 TAGP、WSO、WLV、WST、WRT 趋势。
- `stacked area`：展示器官分配结构，但必须保证单位一致。

诊断规则：

- `TAGP` 高而 `WSO/TWSO` 低：提示光合产物未有效转化为经济产量，可能存在贪青徒长、后期氮肥过量或异常气候影响。
- `WLV/TWLV` 在开花后断崖式下降：提示早衰风险，可能与严重缺水、脱肥或病虫害有关。
- `WSO/TWSO` 在 DVS 约 1 后仍迟迟不上升：提示产量形成能力不足。

### 3. chart — 逐日生长速率与逆境诊断

对应资料图表：`crop_growth_rate`。

来源：`csv_content[]` 有效日序列和天气/逆境字段。

优先字段：

- 生长速率：`CGR`，或可由 `TAGP` 相邻有效值差分得到的日增量。
- 累积生物量：`TAGP`。
- 逆境条带：`TMAX`、`TMIN`、`RAIN`、`IRRAD`、干旱连续天数等字段。

推荐 ECharts：

- 上层 `line/scatter`：CGR 原始曲线和 7 日趋势线。
- 中层可用 `custom` 不安全时，改用 `bar`/`heatmap` 表示高温、霜冻、干旱、暴雨、寡照事件。
- 下层可用 `line` 或面积图展示潜在基线与实际 TAGP 的差距；只有基线可追溯时才生成损失面积。

诊断规则：

- CGR 峰值期是水肥投入回报最高窗口，可建议提前 3-7 天完成追肥和灌溉布局。
- CGR 低谷与高温/干旱/寡照/暴雨条带重合：说明逆境是增长放缓原因。
- 开花期高温、灌浆/膨大期干旱+高温、苗期霜冻、快速生长期寡照+暴雨是高风险组合。
- 逆境后 CGR 3-5 天恢复可视为可逆胁迫；7-14 天缓慢恢复为中度损伤；长期不恢复说明减产基本形成。

### 4. chart — 冠层发育与物候进程

对应资料图表：`canopy_phenology`。

来源：`summary_report_json` 和 `csv_content[]`。

优先字段：

- `LAI` / `LAIMAX`
- `DVS`
- `DOS`、`DOE`、`DOA`、`DOM`、`DOH`、`DOV`

推荐 ECharts：

- `line` 双轴：LAI 与 DVS 同图展示。
- 用 `markLine` 或 `markPoint` 标注播种、出苗、开花、成熟、收获等日期；日期缺失时不要补猜。

诊断规则：

- DVS 到 1.0（开花）时 LAI 应达到合理峰值；禾谷类通常 4.0-6.0，块根类可达 3.5-5.0。
- 开花期 LAI < 3.0：提示前期营养不良、低温干旱或播种密度不足。
- DVS 曲线斜率过陡：提示高温导致生育期压缩，干物质积累时间不足。
- DVS 终值 < 2.0：说明模型期内未完全成熟，产量潜力未充分释放。

### 5. chart — 土壤水分与干旱胁迫

对应资料图表：`water_status`。

来源：`csv_content[]`、`terminal_report_json`。

优先字段：

- `SM`：土壤含水量。
- `RFTRA`：蒸腾削减因子。
- `TRA` / `WTRAT`：蒸腾。
- `RAINT`、`TOTIRR`、`TOTINF`、`PERCT`、`EVST`、`EVWT`、`LOSST`、`TSR`：水分平衡。

推荐 ECharts：

- `line`：SM 与 RFTRA 趋势。
- `bar` / 堆叠 `bar`：水分平衡收支。

诊断规则：

- `RFTRA < 0.9`：提示供水开始限制蒸腾，应关注灌溉。
- `RFTRA < 0.5` 且出现在开花、灌浆或块根膨大期：高风险，可能直接影响产量形成。
- 最后有效 `SM < 0.20`：高优先级补水建议。
- `TOTIRR = 0` 且 `WTRAT` 明显大于 `RAINT`：模型期主要依赖降雨，需关注后续灌溉安排。
- `PERCT > 0` 且降雨/入渗较高：关注水肥淋失风险。

### 6. chart — 氮素动态诊断

对应资料图表：`nitrogen_dynamics`。

来源：`csv_content[]`、`summary_report_json`。

优先字段：

- `NuptakeTotal`
- `Actual N %` / 实际氮浓度字段
- `Critical N %` / 临界氮浓度字段
- `NNI`

推荐 ECharts：

- `line`：累计吸氮量、实际氮浓度、临界氮浓度、NNI。
- `markLine`：NNI=1.0，作为缺氮判断基准。

诊断规则：

- `NNI < 1.0`：氮素亏缺，需考虑追肥或优化方案。
- 实际氮浓度下降过快或成熟期偏低：提示氮供应不足，影响产量或品质。
- 拔节后实际氮浓度长期偏高：提示奢侈吸收，可能浪费氮肥并增加病虫害/倒伏风险。
- 块根块茎类作物后期氮浓度偏高：提示贪青晚熟、含糖率或淀粉积累风险。

### 7. chart — 生物量增长器官分配

对应资料图表：`crop_growth_partitioning`。

来源：`csv_content[]` 中各器官生物量累计值。

优先字段：

- `WRT`、`WLV`、`WST`、`WSO`
- 或 `TWRT`、`TWLV`、`TWST`、`TWSO`

推荐 ECharts：

- 有逐日增量时用 `stacked area/bar` 展示各器官分配速率。
- 只有累计值时，用堆叠面积展示累计器官结构，不要伪装成“日增长速率”。

诊断规则：

- 开花期（DVS≈1.0）后，叶/茎增长应趋缓，贮藏器官/籽粒增长应明显增强。
- 收获前仍有大面积叶片增长：提示贪青晚熟或后期氮肥/降雨刺激过强。
- WSO 峰值低、持续时间短：提示经济产量形成能力不足。

## 极端天气与风险统计

如果 `csv_content[]` 或报告聚合字段包含天气数据，生成风险摘要或 chart；否则跳过，不补猜。

| 指标 | 规则 |
|---|---|
| 高温热害天数 | `TMAX >= 30°C` |
| 霜冻天数 | `TMIN <= 0°C` |
| 暴雨天数 | `RAIN >= 50mm` |
| 最长连续干旱期 | 连续有效降雨 `RAIN <= 0.1mm` 的最长天数；超过 14 天通常构成严重水分胁迫 |
| 寡照天数 | `IRRAD <= 5 MJ/m2/d` |

风险解读必须结合生育阶段：同一逆境出现在开花、灌浆、块根膨大等关键期，优先级高于普通营养生长期。

## recommendation 规则

建议必须引用 WOFOST 字段值或可追溯规则，最多 3 条，按优先级排序。

| 条件 | priority | title 模板 |
|---|---|---|
| 最后有效 `SM < 0.20` 或 `RFTRA < 0.5` | high | "模型显示水分胁迫偏重，建议优先补水" |
| `0.20 <= SM < 0.25` 或 `RFTRA < 0.9` | mid | "模型显示供水趋紧，建议持续监测墒情" |
| 高温/干旱/寡照与开花或灌浆/膨大期重合 | high | "关键生育期遭遇复合逆境，建议启动应急干预" |
| `NNI < 1.0` | mid | "模型显示氮素供应不足，建议评估追肥窗口" |
| 后期氮浓度偏高且经济器官增长弱 | mid | "存在贪青晚熟风险，建议控制后期氮肥和大水刺激" |
| `TAGP` 高但 `TWSO/WSO` 低 | mid | "生物量向经济产量转化不足，建议复盘后期水肥和逆境影响" |
| `DVS < 2.0` 且接近收获日期 | mid | "模型显示成熟度不足，建议评估收获窗口和品种/播期适配" |
| `PERCT > 0` 且降雨/入渗较高 | low | "存在渗漏消耗，关注水肥淋失风险" |

无明显风险时，生成低优先级建议或 Markdown 一句：`"WOFOST 模型结果未显示明显水分、氮素或生长异常，建议按当前生育阶段继续跟踪。"`

## 与 get_plot_info 的关系

地块情况综合报告可同时包含：

1. WOFOST 模型摘要和趋势（重点）。
2. `get_plot_info` 基础快照：面积、作物、当前阶段、评级。
3. WOFOST 风险建议优先；`get_plot_info` 的阶段注意事项作为补充建议。

不要让基础快照卡片挤掉 WOFOST 图表。报告容量有限时优先保留 WOFOST KPI、生物量/产量图、水分/氮素/物候图和模型建议。

## 禁止项

- 不要原样输出完整 `csv_content[]`。
- 不要输出 `NaN`、空值或 0 占位指标。
- 不要把 `plot_no`、`report_no` 当成地块业务名称。
- 不要把模型模拟值表述为实际测产或已经发生结果。
- 不要用 table 替代 WOFOST 趋势、水分平衡、生物量/产量结构图。
- 不要根据图表资料自行编造不存在的 KPI；资料只提供诊断口径，事实值必须来自 WOFOST payload 或可追溯计算。
