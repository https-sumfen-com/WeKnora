# get_farming_operation_list 字段提取规则

农事操作列表用于选择 `add_farming_record.matter_id`。返回项很轻量，通常只有事项 ID 和事项名称。

## 返回结构

上游返回数组：

```json
[
  {
    "id": 127,
    "name": "播前整地"
  }
]
```

## 字段含义

| 字段 | 含义 | 使用规则 |
|---|---|---|
| `id` | 农事事项 ID | 用户选择后传给 `add_farming_record.matter_id` |
| `name` | 农事事项名称 | 展示给用户选择 |

## 回答规则

- 用户要选择农事事项时，列出事项名称和 ID。
- 用户选择"播前整地"后，新增农事记录传 `matter_id=127`。
- 不要根据事项名称自行生成 ID。
- 不要把事项列表当成已保存的农事记录。
- 空数组时说明"未查询到可用农事事项"。
